⚡ Guaranteed Shortest

Breadth-First Search (BFS)

Data Structure: std::queue (FIFO Queue)

Explores the maze level-by-level in concentric rings from Start. Mathematically guarantees finding the shortest path in unweighted mazes.

Time: O(V + E) Space: O(V) Queue
🔍 Deep Traversal

Depth-First Search (DFS)

Data Structure: std::stack (LIFO Stack)

Uses a stack-based depth-first exploration strategy to dive deep into corridors until hitting dead ends, then backtracks.

Time: O(V + E) Optimality: Non-optimal
⭐ Optimal & Heuristic

A* Search Algorithm

Data Structure: std::priority_queue (Min-Heap f = g + h)

Uses path cost so far g(n) combined with Manhattan distance heuristic h(n) to prioritize expansion towards the goal while guaranteeing the shortest path.

Evaluation: f(n) = g(n) + h(n) Optimality: Shortest Path
🌐 Optimal Shortest Path

Dijkstra's Algorithm

Data Structure: std::priority_queue (Min-Heap dist)

Finds shortest paths using accumulated path costs. Expands nodes in strict order of cumulative distance from Start with uniform edge weights.

Weights: Uniform (Cost = 1) Optimality: Shortest Path
🎯 Fast Heuristic

Greedy Best-First Search

Data Structure: std::priority_queue (Min-Heap h)

Prioritizes cells purely based on estimated distance to the goal h(n). Rapidly moves towards the goal but is not guaranteed to produce a shortest path.

Heuristic: Manhattan |Δr| + |Δc| Optimality: Non-optimal
